# План розробки «Головного тренера»

Браузерний футбольний менеджер з реальними даними: УПЛ і топ-5 ліг Європи (~112 клубів, ~3 000 гравців),
сезон 2026/27. Мова — українська. Кожен етап — окремий PR у `main`.

## Технічні рішення

- Чистий HTML, CSS і JavaScript без збірки: звичайні `<script>`, щоб гра відкривалась подвійним кліком.
- База — `data/db.js` (`window.FM_DB`), її збирає `tools/build-db.js` з Wikipedia і Wikidata.
- Збереження — `localStorage`, пізніше експорт та імпорт файлу.
- Випадковість у матчах — генератор із зерном (однаковий сейв дає однакові результати).
- Тести логіки — `node --test`.

## Модель даних (data/db.js)

- `leagues[]`: `id` (eng, esp, ita, ger, fra, ukr), назва, країна, кількість клубів.
- `clubs[]`: `id`, ліга, код, назва (укр.) і `nameEn`, повна назва, стадіон, місткість, рік заснування, кольори,
  `strength` (0–1, місце за два минулі сезони), `players[]`.
- `players[]`: `id`, клуб, ім'я (укр.) і `nameEn`, дата народження, країна (код ФІФА), номер, ролі
  (GK, CB, FB, DM, CM, AM, W, ST) і сторона, зріст, матчі й голи за збірну та в лігах, оренда,
  `ca`/`pa` (1–200), `attrs` (1–20), `value` (млн €).

Атрибути польових: удар, пас, дриблінг, подачі, відбір, гра головою, рішення, позиціонування, відкривання,
працездатність, швидкість, витривалість, сила. Воротарів: реакція, гра руками, один на один, гра на виході,
гра ногами, рішення, позиціонування, швидкість, витривалість, сила.

## Що генерується, а не береться з реальності

- атрибути, рівень, потенціал і ціна — формула з фактів (див. README);
- у наступних етапах: контракти й зарплати (відкритих даних немає), юнаки, що з'являтимуться через роки.

## Двигун матчу (js/match.js)

1. Склад під схему (4-3-3, 4-2-3-1, 4-4-2, 3-5-2): для кожної позиції — найкращий гравець за рейтингом ролі
   (зважені атрибути) з урахуванням того, наскільки позиція йому рідна.
2. Сили ліній 1–20: атака, контроль м'яча, оборона, воротар — середнє зважене по гравцях на полі, з втомою.
3. Щохвилини: частка володіння з контролю м'яча (перевага господарів), шанс моменту, реалізація
   (атака проти оборони й воротаря, удар і рішення того, хто б'є), пенальті, картки.
4. Хто програє після 60-ї — тисне, хто веде після 70-ї — береже рахунок. Заміни суперника на 60/70/80-й.
5. Підсумок: трансляція українською (імена лише в називному відмінку), статистика, xG, оцінки 3–10, найкращий гравець.

Калібрування — `tests/match.test.js` (тисячі матчів на реальній базі): ~2,74 гола за матч, 43% / 26% / 31%,
~3,8 жовтої й ~0,09 червоної за матч; Реал удома проти Расінга виграє ~86%.
