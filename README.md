# Головний тренер

Браузерний футбольний менеджер для себе: реальні ліги, клуби й гравці.
Шістнадцять ліг: УПЛ і Перша ліга України, Англія, Іспанія, Італія, Німеччина, Франція (кожна з другим дивізіоном),
а також Португалія, Нідерланди, Туреччина й Польща. Підвищення й виліт, єврокубки за новим форматом, збірні.
Старт — сезон 2026/27, далі — скільки завгодно сезонів.

У грі: тактика й матчі наживо з керуванням, сезон із таблицями, кубки країн і єврокубки, розвиток і травми
гравців, юнаки з академій, трансфери й контракти, фінанси й правління (можуть звільнити), мораль, промови й
прес-конференції, редактор гравців і клубів, збереження у файл. Як усе влаштовано — екран «Довідка» в грі
й `docs/PLAN.md`.

## Як грати

- **Локально:** відкрийте `index.html` у браузері (подвійний клік). Сервер не потрібен.
- **Онлайн:** увімкніть GitHub Pages (Settings → Pages → гілка `main`, папка `/`), і гра буде за посиланням
  `https://<ваш-логін>.github.io/football_manager/`. Для приватного репозиторію GitHub Pages доступний лише на
  платних планах GitHub; на безкоштовному — тільки для публічних.

Збереження лежить у браузері (`localStorage`), тож на іншому пристрої чи в іншому браузері кар'єра своя.

## Звідки дані

| Що | Джерело |
|---|---|
| Ліги, склади, клуби, стадіони, кольори | Wikipedia (CC BY-SA 4.0) |
| Дата народження, зріст, позиція, матчі за клуби й збірну | Інфобокси статей гравців у Wikipedia |
| Українські назви клубів і гравців | Wikidata (CC0) |
| **Атрибути 1–20, рівень, потенціал, ціна** | **Власна формула** (`tools/lib/ratings.js`) |

Атрибутів у справжньому футболі немає, а бази інших ігор чужі, тож ми рахуємо їх самі з фактів:
сила ліги, місце клубу за два минулі сезони, вік, позиція, матчі за збірну (з урахуванням її рівня),
регулярність ігор, зріст, результативність. Логотипів немає (торгові марки), замість них — кольори клубу.

## Як оновити базу

```bash
node tools/build-db.js     # у хмарному контейнері: NODE_USE_ENV_PROXY=1 node tools/build-db.js
```

Скрипт збирає дані заново (Wikipedia обмежує частоту запитів, тож перший запуск триває десятки хвилин;
відповіді кешуються в `.cache/` на тиждень) і пише `data/db.js` та `data/db-report.txt` зі списком
того, що не вдалося розпізнати.
